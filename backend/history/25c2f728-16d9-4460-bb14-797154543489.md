**Assistant:** **Why use `nmap -p139,445 --script smb-os-discovery <target>`?**

| Reason | What it does |
|--------|--------------|
| **Reconnaissance of SMB services** | Ports 139 and 445 are the classic SMB ports. This scan tells you whether those services are open, closed, or filtered. |
| **OS‑level details** | The `smb-os-discovery` script returns things like Windows version, build number, MAC address, NetBIOS name, workgroup, and system time—useful for identifying the exact OS/version an attacker may be targeting. |
| **Security assessment** | Knowing which SMB version is running helps you decide if it’s vulnerable (e.g., CVE‑2017‑0144 “EternalBlue” affects Windows Vista, XP, etc.). |
| **Network hygiene check** | In a corporate or home network, confirming that only authorized hosts expose these ports reduces the risk of accidental exposure. |
| **Automation / reporting** | Nmap can be scripted into larger audit jobs (e.g., “run this scan on every server nightly”). |

In short, the command is a quick way to gather detailed information about SMB‑related services on a host, which is valuable for security audits, penetration testing, or simply checking whether those ports are unintentionally open.
