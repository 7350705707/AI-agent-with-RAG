### From general knowledge (Indian perspective)

A “hardware spare” in this context usually refers to a **malicious device that mimics legitimate hardware**—such as a USB stick, dongle, or network adapter—that is inserted into a victim’s system. The attacker then uses it to:

1. **Steal data** (e.g., credentials, documents) directly from the host.
2. **Install persistent back‑doors** that survive OS reboots because they are rooted in hardware.
3. **Facilitate “spare” attacks**: the device is left behind or removed after the breach, making forensic removal difficult.

#### Why it’s called “spare”
- The attacker may keep a spare copy of the same malicious hardware (e.g., another USB stick) to reuse later if the first one is detected and destroyed.
- In India, where many organizations rely on cheap, readily available USB devices for data transfer, such attacks exploit that trust.

#### Typical indicators
| Indicator | What it means |
|-----------|----------------|
| **Unfamiliar device** appearing in Device Manager/Device Tree | Could be a Trojan‑USB or similar. |
| **Unexpected network activity** after plugging in the device (e.g., outbound connections to unknown IPs) | The device may be exfiltrating data. |
| **No removable media logs** on Windows Event Viewer for USB insert events | Attackers often use custom drivers that don’t generate standard logs. |

#### Defensive measures
- **Device whitelisting**: only allow known, trusted hardware (e.g., corporate‑issued dongles) to be connected.
- **Behavioral monitoring**: detect anomalous data transfers from newly inserted devices.
- **Regular audits** of removable media inventory, especially in Indian enterprises where many workstations use personal USB sticks.

In short, “hardware spare phishing” isn’t a formal term in the reference material; it’s an informal way to describe using leftover malicious hardware (like a USB stick) as part of a spear‑phishing campaign. The core idea is that the attacker leaves behind or keeps a spare piece of the device so the breach remains hidden and can be reused.
