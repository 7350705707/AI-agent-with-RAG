**Assistant:** The **core function** of `create_token` is to **generate a signed JSON Web Token (JWT)** that can be used to verify the caller’s identity and permissions in a secure API.  

It does this by:

1. **Assembling a payload** containing:
   * `sub` = user identifier  
   * `username` = user login name  
   * `role` = permission level  
   * `agents` = list of allowed agents (optional)  
   * `exp` = expiration timestamp (now + JWT_EXPIRE_HOURS)  
   * `iat` = issued‑at timestamp (now)

2. **Encoding** the payload with a secret key (`JWT_SECRET`) using an algorithm such as HS256.

3. Returning the resulting JWT string, which the client can send back to the server for authentication checks.
