### From general knowledge:

A **hardware spare** in cybersecurity is a malicious device that mimics legitimate hardware—commonly a specially‑crafted USB stick, dongle, or network adapter. Attackers insert this device into a victim’s computer or network equipment to deliver payloads such as data exfiltration tools, backdoors, or ransomware without triggering software anti‑malware detections.

**How it works**

1. **Physical delivery** – The attacker gives the device to an employee (e.g., via “spare” USB key) or places it in a workstation.  
2. **Automatic execution** – When the device is plugged in, its firmware runs code that can install malware, copy files, or create network connections.  
3. **Stealth** – Because it operates at the hardware level, it bypasses many software‑based security controls.

**Indian context**

- The Indian IT Act 2000 and the recent Cyber Crime (Prevention) Act 2013 criminalise such attacks under provisions for “unauthorized access” and “data breach.”  
- Enterprises are advised to enforce device‑acceptance policies, use hardware‑based authentication (e.g., TPM), and regularly update firmware.  

In short, “hardware spare phishing” is a variant of spear‑phishing that leverages a disguised hardware device as the delivery mechanism for malware.
